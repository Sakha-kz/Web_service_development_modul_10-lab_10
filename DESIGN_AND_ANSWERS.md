# Отчёт и результаты работы: Модуль 10 (Лабораторная работа / СРСП)

## 📌 Архитектура Student Grade Manager
1. **Вложенные структуры и срезы:**
   ```go
   type Student struct {
       ID     int
       Name   string
       Group  string
       Grades []int // оценки 0-100
   }
   ```
2. **Динамическое добавление оценок:**
   ```go
   m.students[i].Grades = append(m.students[i].Grades, grade)
   ```
3. **Группировка по учебным группам (Map Reduction):**
   ```go
   groupSums := make(map[string]int)
   groupCounts := make(map[string]int)
   for _, s := range m.students {
       for _, g := range s.Grades {
           groupSums[s.Group] += g
           groupCounts[s.Group]++
       }
   }
   ```

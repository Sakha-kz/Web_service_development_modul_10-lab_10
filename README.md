# Модуль 10. Лабораторная работа / СРСП: Student Grade Manager на Golang

Лабораторная работа (СРСП) по дисциплине «Разработка веб-сервисов» (CSE5032).  
Кафедра Программной инженерии, Институт Автоматики и информационных технологий.

---

## 🎯 Цель работы
Освоить вложенные срезы, агрегацию данных и группировку на языке Go:
- Структура `Student` со вложенным динамическим срезом оценок `Grades []int`;
- Добавление оценок через встроенную функцию `append()`;
- Расчёт среднего балла студента, группы и всей совокупности;
- Группировка успеваемости по группам через карту `map[string]float64`;
- Выявление неуспевающих студентов с баллом ниже 50.
